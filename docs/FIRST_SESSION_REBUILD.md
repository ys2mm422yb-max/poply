# First Session Rebuild

Start main: `a8fdca6076884882e1beed332994a7140b465e55`
Branch: `feature/first-session-alive`

## Player problem
The purpose loop is now readable, but the first session is still too repetitive and the Place is not desirable enough. A player can understand that Stars finance `Lichter` while still feeling that the actual play is three similar one-item jobs followed by a small static SVG change.

This rebuild optimizes for **events, variety, visible transformation and consequence**, not more explanation text.

## Core promise
The first minutes should demonstrate the real Poply loop quickly:

**merge → serve → immediate visible build → new gameplay possibility → richer order → stronger build → living Place**

The first real service must put the player close to or directly at a visible restoration payoff. Direct order repetition is forbidden. Place upgrades must materially alter the scene and progressively unlock broader order content.

## Seven blocks
1. First Session / Level 1 redesign.
2. Order variety and anti-repeat selection.
3. Place 01 visual transformation.
4. Living world motion with Reduced Motion safety.
5. Upgrade-driven gameplay unlocks.
6. Daily Goal variety without fixed daily repetition.
7. UI cleanup plus exact-head mobile WebKit and screenshot acceptance.

## Coordination boundary
Open PR #99 owns persisted Guest Loyalty / guest-visit Collection progression. This rebuild may change normal order selection/presentation, but it must not overwrite PR #99's persisted guest visit state or Collection loyalty UI.
