For the active AAA rebuild, real mobile screenshots are authoritative visual evidence.

Before calling a visible milestone complete:
- compare the deployed iPhone result against `docs/AAA_REBUILD_PLAN.md`;
- read the latest dated screenshot-QA document;
- do not equate structural completeness with production quality;
- keep Milestone B open when Place/Orders/Board still read as flat concept art, web cards, dead grid space or mixed visual language.
